# Interface screenshots

Images used on the GitHub project page and on the front page of the HACS repository
(dielessen/openthermostat-ha, whose README is generated by `scripts/publish_hacs_repo.py`).

- **HA 1.0.0rc6 dashboard (5 November 2026):** the generated Home Assistant dashboard of
  `release-1.0` (e10bdee1, E32 rc.5 with HA 1.0.0rc6), photographed in a real Home Assistant
  Core 2026.10.4 that `tools/dev/ha-demo` starts in an isolated namespace with a fake E32, a
  demo user and fictitious demonstration data (its `scenario.py`). No real E32, broker or Home
  Assistant instance was contacted; the sidebar is the demo's own. Saved as 256-colour PNGs.
  - `ha-dashboard-rc5.png`: the Overview at 1280 px: the house card (what the boiler does, the
    living room, hot water, gas and burner starts today, the day so far), the rooms with their
    chips, Today and House.
  - `ha-dashboard-boiler-rc5.png`: the Boiler tab, cropped after the first charts: the Now
    card, today and this week, hot water, gas and burner hours per day, what the boiler does.
  - `ha-dashboard-learning-rc5.png`: the Learning and settings tab, cropped after the first
    rows: what the E32 knows, water temperature by outdoor temperature, what stood out,
    yesterday in figures and missed comfort per day.
  - `ha-dashboard-phone-dark-rc5.png`: the Overview at phone width (390 px, 2x) in the dark
    theme, full length.
- **E32 pages rc.5 (5 November 2026):** the E32 web interface of `release-1.0` (004dadc1, E32
  1.0.0-rc.5), rendered by `tools/dev/e32-shots` in headless Chromium from one fictitious demo
  house (a living room with floor heating and a tado-style thermostat, two radiator rooms off, a
  Nefit EcomLine-type boiler, knowledge 78 %, a learned curve): mocked HTTP responses for the E32
  pages and a synthetic `hass` object for the card. No device, broker or Home Assistant instance
  was contacted; no data from a real installation. Saved as 256-colour PNGs.
  - `e32-overview-rc5.png`: Overview with the rooms and their last 24 hours, the boiler and its
    history, cropped above How this works; `e32-overview-phone-dark-rc5.png` shows the top at
    phone width (390 px, 2x) in the dark theme, cropped after the first room.
  - `e32-rooms-rc5.png`: Rooms page with editing unlocked and the living room's week program in
    the visual planner, cropped after the week preview.
  - `e32-boiler-rc5.png`: Boiler page, the Now panel with current values and hot water today.
  - `e32-home-learned-rc5.png`: Home page: the water temperature chart (standard and learned line,
    now) and "What the thermostat has learned" with what the E32 knows (78 %), what it still
    learns, yesterday compared with usual, the room's free heat and the house.
  - `ha-week-card-rc5.png`: the Home Assistant week planner card (`e32-week-card.js` with
    `week-editor.js`), rooms as tabs and the Comfort, Eco and Night levels, rendered outside Home
    Assistant with only its default light card style standing in for `ha-card`.
- **1.0 rc.2 (2 November 2026):** the interface of `release-1.0` (92a9d03, rc.2 in
  preparation), rendered locally in headless Chromium with fictitious demonstration data:
  mocked HTTP responses for the E32 pages, a synthetic `hass` object for the Home Assistant
  card. No device or Home Assistant instance was contacted; no data from a real installation.
  Saved as 256-colour PNGs.
  - `ha-week-card-rc2.png`: the Home Assistant week planner card (`e32-week-card.js` with
    `week-editor.js`), rooms as tabs and the Comfort, Eco and Night levels. Rendered outside
    Home Assistant: only Home Assistant's default light card style stands in for `ha-card`;
    no sidebar or other Home Assistant interface is drawn.
  - `e32-home-learned-rc2.png`: Home page, "What the thermostat has learned" (per room,
    the house and boiler, and what the self-tuning would change during the trial run).
  - `e32-overview-rc2.png`: Overview with rooms and their last 24 hours, the boiler and the
    boiler history; `e32-overview-phone-dark-rc2.png` shows its top at phone width (390 px,
    2x) in the dark theme.
  - `e32-rooms-rc2.png`: Rooms page with editing unlocked and the living room's week program
    in the visual planner.
  - `e32-boiler-rc2.png`: Boiler page, the "Now" panel with current values and hot water today.
- **Beta.18 (29 October 2026):** the shipped E32 beta.18 web interface, rendered locally
  in headless Chromium with fictitious demonstration data (mocked HTTP responses). They are
  not captures of a live device and contain no data from a real installation.
  - `e32-overview-beta18.png`: Overview with rooms, trend lines, boiler request and boiler
    values; `e32-overview-phone-beta18.png` shows the same page at phone width (390 px).
  - `e32-rooms-beta18.png` and `e32-rooms-dark-beta18.png`: Rooms page in the light and dark
    theme, read-only because the rooms are managed in Home Assistant, with the
    "Edit here anyway" option, the shadow-mode comparison and the boiler flow limits.
  - `e32-boiler-beta18.png`: Boiler page with current values, burner starts, hot water today
    and all received boiler entities (setting changes are read-only in this firmware).
  - `e32-sensors-beta18.png`: Sensors page with nearby and paired Bluetooth thermometers.
  - `e32-about-beta18.png`: System → About with the password card.
- `ha-room-dev24.png`: the shipped Home Assistant frontend rendered locally with example
  data and an explicit demonstration label; not a live HA capture and no proof of physical
  control.
- `e32-dashboard-alpha18.png`: an actual capture of an installed E32 (alpha.18), cropped to
  the product panel.
- `e32-keteltest-alpha18.png`: actual passive reception diagnostics on the same E32
  (alpha.18). Stale or unreliable fields stay visible; transmitting is blocked.

The screenshots contain no browser address bar, credentials, private sidebar or other
Home Assistant dashboards. Dimensions, versions and hashes are listed in
[screenshots.json](screenshots.json).
