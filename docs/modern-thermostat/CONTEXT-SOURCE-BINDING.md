# Logical comfort sources — explicit native product binding

This increment connects SOURCE-owned contact/person report adapters to the **existing** native HA entry setup, ShadowRuntime state-event listeners, ShadowClient owner reset, original v1 observations and actual ShadowController/EffectiveTarget. It is not a second service, scheduler, collector, transport, persistence namespace or unused policy kernel. No firmware/wire/schema/model/storage/partition/flags/default selection changes. Empty source selection preserves existing conservative last_changed120s behavior.

## Source contract

A reviewed source bundle may populate `_COMFORT_CONTEXT_SOURCE_PROFILES` in integration source. Each immutable `ContextSourceProfile` pins native entry unique ID, exact room, window/presence kind and stable registry domain/platform/unique ID, version1 and a **synchronous integration-specific callback**. The callback returns a bounded `ContextReport` identity/time only for a genuine new logical source report under its integration's separately reviewed producer contract. There is no built-in production adapter, profile discovery, GUI override or trust in arbitrary HA `last_reported`, `last_seen` or incoming attributes. Fixture proof attributes are solely the native test adapter boundary, NOT a generic product qualification mechanism.

At most16 pins (two per each of8 rooms) are accepted. Duplicate/excess/unknown-schema/async callback/wrong bound source/profile fails closed. Only matching native entry selection may install the bundle; an unrelated entry cannot be captured. Native setup emits a non-secret explicit configuration error for invalid selection/binding before connection creation. No profile/override is persisted or restored by this change. Graph DATA-only runtime explicitly refuses these control-context pins; API1 defaults remain unchanged.

The SAME native changed/reported events call the adapter. The getter/poll/temperature event does not. Restored/unavailable/unknown/future/stale/malformed/out-of-order reports remove usable proof. A new identity and strictly increasing sample timestamp can refresh unchanged logical value; exact duplicate can only retain its still-valid original monotonic deadline. A changed replay cannot refresh it. Lost evidence, registry rebind, owner reset/reconnect, monotonic reversal/expiry or stop destroys the usable proof while bounded replay watermarks remain. A cache read or exact old report cannot restore it. A genuinely new report is required after owner loss, not an optimistic admission from the adapter.

The existing v1 firmware lifetime is **still exactly120000ms**. No extended TTL or reinterpretation of units is introduced. Sender source age plus conservative original grant elapsed and receiver monotonic age still bound freshness in firmware; newer temperature reports do not re-age old contact proof. This is not support for indefinitely quiet contacts. A real integration without a qualified fresh logical report continues to become unknown. The source callback needs independent real-device/producer qualification; a successfully installed source profile is not commissioning.

## Priority, status and safety

Known closed contact/home may enable the existing logical target calculation only. Unknown presence never means away; a named person zone is not silently treated as away. Window affects only its bound room; the existing limit/off/frost/window/override/away/schedule priority stays unchanged. Context reports reuse the original temperature Observation/deadline and never create a temperature report or extend temperature freshness. No physical frost, hydraulic readiness, delivery, learning/model or actuation capability is granted.

Existing native climate attributes/diagnostics expose only per-kind `qualified_logical_report`, `source_report_unknown`, `conservative_state_age` or `not_configured`. Callback exceptions have a fixed error code; report identities/times, callback source identity, payloads and private source pins are not exported. Firmware boiler/actuator/supervisor output flags remain false; no runtime action or local source selection occurred.
