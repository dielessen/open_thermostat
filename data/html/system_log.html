System log

Recent logs are kept in RAM and disappear after a restart. Configure a syslog server for longer retention.


  

  

    Technical details
    
The source filter only changes this view. EMS logs include received frames processed by the controller, not a complete bus recording. Clearing removes both ESP and EMS local logs.

    
Memory and stack

    
Reserves the E32 had at its lowest point since startup. Very low values can explain a restart.

    

    
Loop timing

    

    
Intervals include network, HTTP and scheduler delays. They are not page-load times. Counters reset after restart; the observation window renews every minute.

  

  

  
Diagnostics console

  
Read-only commands for troubleshooting. Type help for the list. The console never changes settings.

  

    
    
    
    
  

  

  
Actions

  
Each action asks for confirmation first. Neither runs while a boiler test, a boiler settings write or a firmware update is in progress.

  

    
    
  

  

  

  

  
Logging settings

  
Choose how much is logged and whether logs also go to a server on your network.

  

    

      
      
      
      
      
      
      
      
    

    
Syslog uses RFC5424 over UDP. Delivery is not acknowledged. Debug and trace produce more traffic; the buffer is bounded and dropped messages are counted.
