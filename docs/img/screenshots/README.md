# Interfacebeelden

Opnamen voor de GitHub-hoofdpagina, 23 oktober 2026.

- `ha-room-dev24.png`: echte uitgeleverde HA-frontendcode lokaal weergegeven met
  voorbeeldgegevens. In beeld en bijschrift staat expliciet dat het een demonstratie
  is; dit is geen live HA-opname of bewijs van fysieke regeling.
- `e32-dashboard-alpha18.png`: echte opname van de geïnstalleerde E32-interface,
  beperkt tot het productpaneel.
- `e32-keteltest-alpha18.png`: echte passieve ontvangstdiagnose op dezelfde E32.
  Verouderde/onbetrouwbare velden blijven zichtbaar; zenden is geblokkeerd.

De HA-demonstratie is gerenderd vanuit de uitgeleverde component met expliciete
voorbeeldinvoer. De E32-beelden tonen de waarden ten tijde van de opname. De screenshots bevatten geen browseradresbalk,
inloggegevens, privézijbalk of andere HA-dashboards.

Afmetingen, versies en hashes staan in [screenshots.json](screenshots.json).
