Firmware update

Releases from dielessen/open_thermostat. Installation starts only when you press the button. Your WiFi, rooms and programs are retained; the web interface is updated with the firmware.

Installed: Loading…

Use your home network and keep the device powered. If downloading or verification fails, the previous firmware remains selected. Test releases are experimental; this firmware does not enable heating yet.

Checks run automatically every 12 hours, starting five minutes after startup. Failed checks retry after 30 minutes. Successful results are reused for five minutes. Installation always requires your confirmation.

Update diagnostics

The last saved checkpoint helps investigate an interrupted update. It does not confirm installation or rollback. Manual uploads are not recorded here.


   

  





Manual upload / recovery

Use compatible app firmware only, never the combined factory file. A SPIFFS upload can replace rooms and programs; it is not needed for normal GitHub updates.



 
Your browser can look up the latest release on GitHub and check a downloaded firmware.bin against its published SHA-256 before uploading. GitHub does not let a web page download the file itself, so download it with the link and choose it below.
